# Server Integrity

Server Integrity provides tools for protecting community builds and managing structure ownership on multiplayer servers.

## Included tools

- **Integrity Gun** — toggles protection against damage and deconstruction. It supports target, connected, matching-connected, and blast-area modes.
- **Ownership Gun** — allows authorized server administrators to assign structure ownership.
- **Integrity Scanner SPU** — highlights protected and unprotected structures when installed in Sensor Lenses.

The three tools are available from the Security Printer. Each recipe requires 1 g of gold and 1 energy, with a 10-second build time. They are also available through the creative spawn menu.

Protection and ownership changes are retained when the world is saved and restarted. In multiplayer, access is governed by the server; single-player users have full access.

Dedicated server installation is required. Client installation is optional.
